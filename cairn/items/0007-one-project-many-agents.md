## Ships

Browse every feed belonging to one project. Worktrees and parallel agents appear together, you switch between them, and you can search across the lot.

## Done when

- [ ] A session's `cwd` resolves to its repo root, so worktrees group with their main checkout
- [ ] The picker groups by project and marks which sessions are live right now
- [ ] Switching between a project's feeds is one keystroke
- [ ] One merged feed can interleave a project's sessions, labelled by origin
- [ ] Search runs across every stored session, not just the open one

## Explicitly not in this milestone

- Watching two feeds side by side in split panes
- Anything that writes into a session
